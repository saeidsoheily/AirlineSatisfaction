# AirlineSatisfaction

## Airline Satisfaction Data ✈️
This dataset contains 129,880 survey responses collected by an airline from passengers after their flights. The survey was designed to evaluate various aspects of the passenger experience — from booking and check-in to in-flight services and baggage handling. The data is anonymized and contains no personally identifiable information (PII). This makes it safe and easy to share for educational and research purposes.


### Content
The dataset consists of 129,880 rows and 22 columns (21 features + 1 target variable), collected from actual airline passengers.
